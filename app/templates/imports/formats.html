Import file formats

Stacks imports two CSV files with a header row: a roster and availability. Column order and capitalisation don't matter, and files saved by Excel are fine. To move from Homebase, fill these in from Homebase's employee list and availability; its "Unavailable" and "Preferred" blocks map to the type column.

Every import is previewed first. A file with any problem is rejected as a whole, and an applied import can be undone while it's the most recent one of its kind.

Roster

One row per employee, matched to existing records by email.

ColumnRequiredMeaning
full_nameYesFull name, shown to supervisors.
preferred_nameYesShown to co-workers on the published schedule.
emailYesMatches records and receives the sign-in invitation. Unique in the file.
campus_idNoUnique across employees.
employment_typeNoregular (default), non_regular (never auto-scheduled) or inactive.
hire_dateNoYYYY-MM-DD.
new_employee_untilNoYYYY-MM-DD; new-employee rules apply until then.
default_pay_roleNoPay role name; created if new.
tagsNoTag names separated by semicolons, such as Shift lead;Cataloguer; created if new.

For existing people, blank optional cells leave current values alone and tags are only added. Wages aren't imported.

full_name,preferred_name,email,employment_type,default_pay_role,tags
Avery Example,Avery,student01@example.edu,regular,Student Assistant,Opener

Availability

One row per block, for the term you choose when uploading. Each person in the file gets exactly these blocks for that term, marked needs review until confirmed. Everyone must already be on the roster.

ColumnRequiredMeaning
emailYesThe employee's email.
weekdayYesMonday to Sunday, or Mon to Sun.
typeYesunavailable or preferred.
start, endNoTimes such as 09:00 or 9:50am. Leave both blank for all day.

Times are kept exactly. For scheduling, unavailability widens to whole 15-minute slots, so a 9:50 end blocks until 10:00.

email,weekday,type,start,end
student01@example.edu,Monday,unavailable,09:00,09:50
student01@example.edu,Saturday,unavailable,,
